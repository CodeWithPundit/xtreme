# Troubleshooting Guide

## Common Issues

### Playback Issues
1. Check network connection
2. Verify stream URL format
3. Check if stream requires authentication
4. Try different video quality

### EPG Not Loading
1. Verify EPG URL in playlist
2. Check XML format
3. Clear EPG cache in settings

### Downloads Failing
1. Check storage space
2. Verify Wi-Fi connection
3. Check if download limit reached
